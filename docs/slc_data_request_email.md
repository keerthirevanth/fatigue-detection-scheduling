# Dataset access request — Sleepy Language Corpus (SLC / "SLEEP")

## Background (why this corpus)

The Sleepy Language Corpus (a.k.a. the **SLEEP** corpus) provides speech samples
labelled with the **Karolinska Sleepiness Scale (KSS, 1–9)** — a validated
sleepiness/fatigue measure. It was used in the INTERSPEECH ComParE *Sleepiness*
sub-challenges (2011 Speaker State; 2019 Continuous Sleepiness). It is the
standard academic benchmark for exactly our task: inferring fatigue from voice.

It is distributed under a licence/EULA for academic research. Access is usually
by request to the challenge organisers (University of Augsburg — Chair of
Embedded Intelligence for Health Care & Wellbeing, Prof. Björn Schuller — and/or
audEERING GmbH).

## Where to send

- Primary: the ComParE / challenge organisers' contact listed on the current
  INTERSPEECH Computational Paralinguistics Challenge page.
- Prof. Björn Schuller's group (University of Augsburg / Imperial College London).
